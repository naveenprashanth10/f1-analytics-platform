## 📌 Overview
The F1 Data & Analytics Platform is a user-focused web application designed to present Formula 1 data in a clean, structured, and interactive way.  
It enables fans and data enthusiasts to quickly explore standings, driver performance, and race insights without navigating complex data sources.

## 🎯 Problem Statement
Formula 1 data is widely available, but it is often:
- fragmented across multiple platforms
- not beginner-friendly
- difficult to explore quickly

This project aims to solve that by delivering a fast, intuitive, and visually structured experience.

## 👥 Target Users
- Formula 1 fans  
- Sports data enthusiasts  
- Users looking for quick performance insights  

## 🚀 Key Features
- Driver & constructor standings  
- Race results and performance insights  
- Clean and intuitive UI for fast navigation  
- Structured data presentation for better readability  

## 🧠 Product Thinking Behind the Build
- Focused on reducing user effort to find key insights  
- Designed layout for quick scanning and comparison  
- Prioritised the most relevant F1 metrics for fans  
- Built as an MVP with scope for analytics expansion
